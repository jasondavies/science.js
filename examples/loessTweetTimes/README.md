This graph plots the observed rate of tweets for [Eric Fischer’s Twitter feed](https://twitter.com/enf/status/671475255202967553) over the period from January 8, 2015 through November 30, 2015 with a [LOESS](https://en.wikipedia.org/wiki/Local_regression) curve fitted to the data using [science.js](https://github.com/jasondavies/science.js).

Forked from <a href='http://bl.ocks.org/mbostock/'>mbostock</a>'s block: <a href='http://bl.ocks.org/mbostock/d8bcc4b130df420d6c40'>Time of Day</a>

Draws from the example [Loess with science.js](http://bl.ocks.org/curran/890f8475dfe06710ee62) for adding the LOESS curve.

Part of a discussion on d3-shape: [Moving averages, line smoothing, etc. #43](https://github.com/d3/d3-shape/issues/43).
